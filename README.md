# NgpCraft: make Neo Geo Pocket Color games

NgpCraft is a free set of tools to make **homebrew games for the Neo Geo Pocket Color (NGPC)** and the Neo Geo Pocket (NGP):
a no-code game maker, a C development kit (SDK), an emulator, a music tracker and more.
Your game runs on real hardware with a flash cartridge, in an emulator, or as a Windows `.exe`.

Pick your path below. Every tool in the toolbox works with both.

## 🎨 Make a game without coding

**[NgpCraft Studio](https://github.com/Tixul/Ngpcraft-studio)**: a visual game maker based on GB Studio 4.3.2.
Build your game with scenes and events, and get a Neo Geo Pocket Color ROM.
Start here.

## 🛠️ Make a game in C / assembly

1. **Learn**
   - [NgpCraft Live Editor](https://github.com/Tixul/NgpCraft_live_editor): learn NGPC programming by editing and seeing the result live.
   - [NgpCraft Dev Wiki](https://github.com/Tixul/NgpCraft_dev_ref): hardware and Toshiba TLCS-900 reference.
2. **Start a project**
   - [NgpCraft Base Template](https://github.com/Tixul/NgpCraft_base_template): ready-to-build project (sound driver, saves, link cable included).
3. **Go further**
   - [NgpCraft Disasm](https://github.com/Tixul/NgpCraft_Disasm): TLCS-900/L1 disassembler for NGP / NGPC ROMs.
   - [Custom sound driver](https://github.com/Tixul/NGPC_sound_driver_custom): standalone version of the driver already included in the template.

## 🧰 Toolbox (for everyone)

| Tool | What it does |
| --- | --- |
| [NgpCraft Emulator](https://github.com/Tixul/Ngpcraft_emulator) | Desktop emulator to test your ROMs. |
| [NgpCraft Web Emulator](https://github.com/Tixul/NgpCraft_web_emulator) | Same core in the browser, to put your game on a website. |
| [NGPC Sound Creator](https://github.com/Tixul/NGPCraft-Ngpc-sound-creator) | Compose and export music and sound effects. |
| [NgpCraft Pixel](https://github.com/Tixul/Ngpcraft_pixel) | Turn images into NGPC-ready graphics. |
| [NgpCraft MCP](https://github.com/Tixul/NgpCraft_MCP) | Work with an AI assistant. No code: describe your game. Dev: debug your ROM. |
| [NgpCraft Toolchain](https://github.com/Tixul/NgpCraft_Toolchain) | ⏳ Not ready yet: open-source compiler, assembler and linker. |

## 📦 Share your game

[NgpCraft Packager](https://github.com/Tixul/NgpCraft-Packager): turn your ROM into a standalone Windows game (`.exe`), no install needed.
